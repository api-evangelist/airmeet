# Airmeet

> Airmeet is a virtual, hybrid and in-person events platform. Its Public API lets you create and manage events (Airmeets), sessions, speakers, booths and event series; manage registrations; read engagement and attendance data; and subscribe to 24+ webhook event triggers. Auth is a two-step flow: exchange an access key + secret key for a 30-day access token, then send it as X-Airmeet-Access-Token.

## APIs

- [Airmeet Public API (OpenAPI)](https://raw.githubusercontent.com/api-evangelist/airmeet/refs/heads/main/openapi/airmeet-openapi.yml): 29 operations across event details, registrations, event management, event series and webhook registration.
- [Airmeet Webhooks (AsyncAPI)](https://raw.githubusercontent.com/api-evangelist/airmeet/refs/heads/main/asyncapi/airmeet-webhooks-asyncapi.yml): the 24+ webhook event triggers.
